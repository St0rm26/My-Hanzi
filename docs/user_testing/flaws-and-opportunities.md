# Flaws and Opportunities

1. The flaw is users not using the personal rating feature the way it was intended to be used. During both user studies, the participant either did not use it to filter characters by difficulty or used it to mark characters as studied. It is likely occurring due to the layout of the character detail page. The user is unable to tell if a character has been studied without clicking the add to collections button, and it is possible to rate a character without studying it, which can be confusing. A future design is to add a studied status indicator with colors and checkmark/cross. In addition, changing where the personal rating is placed to be close to the title to make the personal rating feature stand out. This is on the **physical** level as the personal rating option is either not made visible enough or substitutes another action that is also on the page. Its severity is **critical** as it might confuse the user as to why the characters they think they've studied are not showing up as such and can prevent them from using the rating filter option if they use collections to assign confidence levels. During the studies, I needed to intervene as one of the participants was confused and lost as to why they saw unexpected results.

2. An opportunity for improvement is noting how studied characters are tracked in the app. This is needed as during one of the studies, the user was confused as to why characters they rated and that were in their created studied collection were not showing up in the benchmarks after filtering. Some fixes could include adding a small note in the benchmarks page or under the benchmarks title that tells the user where it reads from. Another way to communicate to the user to use the default "Studied" collection is perhaps giving it some sort of special outline/color. This is on the **linguistic** level as users might be confused as to what it means to track a character and would not know that the "Studied" collection needs to be used. Its severity is **critical** as during a study, the participant thought the filter by studied menu in the benchmarks page was broken.

3. An opportunity is allowing users to select multiple characters at once. While going through the app myself and seeing others use it, I found it very slow to manually add multiple characters from the search results page or from a benchmark. Some ways that I can fix this is perhaps allowing the user to click and drag to select multiple characters or add some button that opens a checkbox for each character cell, allowing one to check all the characters they want to perform an action to. This is on the **physical** level as it involves the user clicking and dragging their mouse to perform actions on characters. Its severity is **minor** because not having this feature is annoying but doesn't prevent the user from making progress.
