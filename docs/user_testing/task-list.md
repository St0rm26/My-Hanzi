# Task List

| Title                                   | Instructions                                                                                                                                                                                                                                                                                       | Rationale                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| --------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Adding Characters to "Studied"          | "You are a Mandarin Chinese learner and heard about MyHanzi. You want to track a couple characters you've already studied, written here:" _hands list with 我 (wǒ), 你 (nǐ), 好 (hǎo), 妈 (mā), and 吗 (ma)_                                                                                       | This task tests multiple parts of the app; it tests the user's ability to register, identify where the search bar is, how it works, and how to add characters to one's collection. Searching and adding characters are the most essential parts of the app, so it is important to see how well a new user can navigate the app.                                                                                                                                           |
| Adding Textbook Characters to "Studied" | "You realize that manually adding all the characters you've studied is very slow. Since all of your Chinese learning has been from one textbook: Basic Mandarin Chinese by Cornelius Kubler, you hope there is a way to add everything that you've learned from that book (only units A, B, and 1) | This task checks how easy it is for the user to realize that public collections exist and are made for the purpose of storing characters from a well-known resource in one place.                                                                                                                                                                                                                                                                                         |
| Creating a TODO                         | "Now that you've added all the characters you wanted to your 'Studied' collection, you know want to make a TODO list of a couple characters you want to study and get more practice on today"                                                                                                      | This task checks to see if the user is able to take advantage of the features in the app to create and manage their own collections for different tasks.                                                                                                                                                                                                                                                                                                                  |
| Sharing with Friends                    | "Your Chinese tutor Jared wants to create lessons specifically for you to help you learn characters. He would like to know which characters you would like help on."                                                                                                                               | This task checks to see if the user can identify that they can share collections with a select audience and navigate the interactions they need to do in order to achieve the goal.                                                                                                                                                                                                                                                                                       |
| Identifying Struggle Points             | "For future study sessions, you would like to focus on characters that you've seen before and studied a bit but are maybe still difficult for you to write. You would like a quick and simple way to do this."                                                                                     | This task is a little bit more complex than the previous ones. It tests to see if the user can 1. figure out that they can assign personal ratings to each character and 2. figure out that they can filter collections by personal rating. The steps to achieving the goal may be a bit confusing as there is no "study recommendations" feature, so I would like to see how well the user can navigate around the app and play with the features to achieve their goal. |
| Identifying Forgotten Details           | "While studying the character structure for 路 (lù), you realize that you spent a lot of time analyzing the structure and stroke order and actually forgot the meaning of it!"                                                                                                                     | This task tests that the user observes that this app is more than just what a character looks like and how to write it. On the character detail page, there is also information about its meaning, which is just as important to know when studying Mandarin.                                                                                                                                                                                                             |
| Identifying Remaining HSK Characters    | "You have an upcoming HSK1 exam and would like to spend some time today discovering which characters you still need to learn to recognize for the test."                                                                                                                                           | This task tests that the user can identify the built-in benchmarks MyHanzi has. More specifically, the character lists for the HSK tests. In addition, it also tests that the user can appropriately use the filter feature on the benchmark page to only show characters they haven't studied. This makes it easier for them to plan their study sessions.                                                                                                               |
| Check off TODO Items                    | "After completing your studying for the day, you would like to check off the items in your earlier created TODO list so that you can focus on something else tomorrow."                                                                                                                            | This is a simple task as it focuses on just one small feature of the app, which is removing characters from collection. MyHanzi has a quick and convenient way to do this, which is by clicking the 'x' button on the character cell in a collection. The goal of the task is to see if the shortcut is placed in a well-designed spot such that the user is always able to find and use it.                                                                              |
