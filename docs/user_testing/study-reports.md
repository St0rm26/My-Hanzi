# Study Reports

## Study Report 1

His first task was to add some characters he already knew to the studied collection, but the task didn't explicitly mention “studied collection.” He was a little confused about how to track learned characters in the app; the idea of using a collection was not intuitive. For the next task, he was to figure out how to speed up adding all characters from a popular resource to a collection. He didn’t know that the public collections page would solve this at first, but eventually got there. When sharing a collection with someone, he looked at a lot of different places, such as the public collections and the "Shared with me" page, before finally finding it. I’m surprised that this is not as intuitive to find; perhaps I need to add a more explicit button on the home page to share collections. There was unexpected behavior for one task: keeping track of characters to study later by difficulty level. He initially approached this by creating a hard difficulty collection and then added characters to it. While adding a character, he noticed the personal rating button. He used that, which was the expected behavior, but still used the collections. The personal rating option might not be obvious at first, and considering that collections are useful for categorizing characters, it makes sense for users to use them to assign difficulties. To fix this, I could make the personal rating option stand out more. He was able to solve the other tasks pretty quickly, such as checking a character's meaning and using the filters. There were some app features that weren't task-specific but still confused the user. For example, he assumed the simplified/traditional dropdown changes the script for the entire app when it was actually a search results filter.
